# Clustered Poisson estimating equations with unequal observation time

This is a fixed-case software check, **not** a repeated-dataset interval-coverage study. The new `fit_poisson_ee(..., exposure_time=t)` accepts one positive finite observation time per row. The existing equal-time method and its installed-R comparisons remain unchanged.

For row \(i\), let \(Y_i\) be its count, \(t_i>0\) its observation time, \(X_i\) its conditional design row, \(w_i>0\) an optional case weight and \(a\) a joint exposure-score intervention. The conditional fitted count is \(\mu_i=t_i\exp(X_i^\top\beta)\). After setting all exposure scores to \(a\) while keeping \(t_i\) and adjustment variables fixed, the predicted count is \(\widehat\mu_i(a)=t_i\exp\{X_i(a)^\top\widehat\beta\}\). The marginal mean model is \(m_i(a)=t_i\exp(\theta_0+\theta_1a)\). The conditional equation sums \(w_iX_i(Y_i-\mu_i)\); the marginal equation sums \(w_i(1,a)^\top\{\widehat\mu_i(a)-m_i(a)\}\) over rows and intervention levels. Both score vectors are summed within cluster before forming the sandwich covariance. Here \(\exp(\theta_1)\) is the rate ratio for one joint-score increase under fixed observation times. This is not a model for time-varying effects, lag structure or informative observation time.

The fixed 16-row example has four clusters and observation times 0.5, 1, 1.5 and 2. The Python offset fit gives log rate ratio **0.5890944859809044**, sandwich variance **0.012331997980818889**, and 95% log-scale interval **[0.371441407849216, 0.8067475641125929]**. The matching Python and installed-R equal-time fits give log mean ratio **1.79175946922805**. Installed R qgcomp **2.19.6** returns that same value and variance even when supplied `offset=log(obstime)`. Its source labels the EE `offset` argument “Not yet implemented”; the Poisson estimating function does not use it. Python deliberately differs when observation times vary. The optional installed-R probe is saved in [poisson-ee-offset-r-check.json](poisson-ee-offset-r-check.json), with pinned [R exporter](export_poisson_ee_offset_r.R), [checker](check_poisson_ee_offset_r.py), and [input fixture](../tests/fixtures/r_poisson_ee_offset_2_19_6.json). The isolated R 4.5.1 library was verified to load qgcomp 2.19.6; Python has no R runtime dependency.

The independent tests check the time-adjusted conditional fit against the separate Poisson solver, zero stacked score at the solution, a finite-difference bread, separately summed cluster meat and sandwich covariance, integer-weight row replication, invariance to a common rescaling of all times, equality with the old method when all times equal one, and rejection of zero, negative, nonfinite and misaligned times. These checks establish the stated fixed-case arithmetic. They do not establish interval coverage with few clusters, overdispersion, informative follow-up, or broader R-package parity. A separate repeated-dataset study would be needed before a calibration claim.
