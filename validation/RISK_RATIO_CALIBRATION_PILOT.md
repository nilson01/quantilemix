# Binary risk-ratio bootstrap timing pilot

The fixed `binary-risk-ratio-known-scores-v1` pilot ran five independent n=500 datasets in each of four planned cells, with 200 fixed-cut row resamples per dataset. This is engineering and feasibility evidence, not an estimate of interval coverage. After the protocol review's case-journal and publication repairs, the same design ran again from the repaired source. The final pilot used one numerical thread on the M3 Mac, completed 20/20 package fits and 4,000 resamples in 1.984 seconds of runner time, and had no captured warnings or failures. `/usr/bin/time -l` measured 100,237,312 bytes maximum resident set size. The checker independently solved all original and resampled logistic score equations in 0.644 seconds, paired all 20 results, found zero independent failures or issues, and had maximum absolute numerical difference 6.3131e-11. Its maximum resident set size was 216,645,632 bytes. The final raw result, retained journal, receipt and audit total under 250 KiB; no swaps were observed.
