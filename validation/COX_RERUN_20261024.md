# Cox fixed-case reference checks

The checks used R 4.5.1 and an isolated installed qgcomp 2.19.6 library.

| Fresh optional check | Cases | Largest absolute reported difference | Saved report |
| --- | ---: | ---: | --- |
| Conditional Cox fit | 2 | `3.05e-15` | [JSON](cox-rerun-conditional-20261024.json) |
| Shared-time Efron ties | 2 | `2.84e-13` | [JSON](cox-rerun-ties-20261024.json) |
| Conditional survival curves | 2 | `4.88e-15` | [JSON](cox-rerun-curves-20261024.json) |
| Marginal Cox fit and bootstrap arithmetic on identical simulated outcomes | 2 | `8.62e-9` | [JSON](cox-rerun-bootstrap-20261024.json) |
| Marginal survival-curve tables on identical simulated outcomes | 2 fits, 8 tables | `1.18e-9` including the degree-two coefficient | [JSON](cox-rerun-survcurve-20261024.json) |

Each checker regenerated R outputs and compared them with the pinned fixtures and current Python results. The largest marginal bootstrap gap is a p-value; the largest survival-table-only gap is `1.67e-10`. These results verify the fixed-case comparisons after the Cox solver repair. They do not compare the end-to-end Monte Carlo event generators, measure repeated-dataset interval coverage, or establish full R-package parity.

The checkers are `check_cox_r.py`, `check_cox_ties_r.py`, `check_cox_curves_r.py`, `check_cox_bootstrap_r.py` and `check_cox_survcurve_r.py` in this directory. Each requires a new output path, the isolated R library, and the Rscript executable. Python package use has no R runtime dependency.
