# Conditional Cox log-hazard offsets

`fit_cox(..., offset=o)` accepts one finite, known **log-hazard offset** per row. The fitted hazard is $h_i(t)=h_0(t)\exp(X_i^\top\beta+o_i)$, where $h_0(t)$ is the baseline hazard, $X_i$ is the exposure-and-adjustment row, and $\beta$ is estimated. The offset coefficient is fixed at one. It affects each risk set and the baseline hazard but does not change exposure cutpoints. It is not an observation-time offset or a time-varying exposure model.

Three fixed 128-row cases from **isolated installed R qgcomp 2.19.6** cover distinct event times, shared event times, and shared times with fractional case weights. They call R `qgcomp.cox.noboot` with `offset(o)` in the survival formula. Python's coefficients, covariance, joint effect, interval, p-value and two-profile conditional survival curves agree within $10^{-14}$ in these cases. The [saved check](cox-offset-reference-results.json) records each field. The optional [checker](check_cox_offset_r.py), [R exporter](export_cox_offset_r.R) and [pinned fixture](../tests/fixtures/r_cox_offset_2_19_6.json) preserve the exact inputs and versions. R is only an optional validation tool; Python fitting has no R runtime dependency.

The saved baseline curves use different conventions. In these fixed cases, R `basehaz(centered=FALSE)` still multiplies the uncentered baseline by the exponential of the mean fitted offset (the case-weighted mean when weights are present). Python stores the **uncentered** baseline. Applying the corresponding offset to each new profile gives the same conditional survival probabilities as R `survfit`. The checker verifies both the R scaling and the final curves; comparing the two raw baseline arrays without this adjustment would be misleading.

An independent three-person risk-set calculation checks the offset partial likelihood, score, information and baseline increments. Finite differences check the score and information. A zero offset recovers the existing fit, and adding one constant to every fitted and predicted offset changes the baseline but not the joint effect or final survival curve. Invalid or missing prediction offsets fail clearly. These fixed cases do **not** establish proportional hazards, independent censoring, causal interpretation, repeated-dataset interval coverage, or support for time-varying effects, clusters or case-cohort sampling.
