# Four-level risk-ratio validation jobs

These Slurm files execute protocol `binary-risk-ratio-four-level-known-scores-v1` on a clean committed source checkout. They are private research checks, not Python runtime dependencies. The first job is a 20-case pilot; the second is the planned 4,000-case study. Run the study only after the reviewed protocol, clean-source server pilot, fresh quota and queue check, and duplicate-run check pass.

| Job | Class and request | Planned work | Output guard |
| --- | --- | --- | --- |
| Pilot | `short`, one CPU, 1 GiB, five minutes | 20 datasets, 4,000 bootstrap draws, all-case independent audit and raw aggregation | under 50 MiB |
| Study | `short`, one CPU, 4 GiB, one hour | 4,000 datasets, 800,000 bootstrap draws, all-case independent audit and raw aggregation | under 100 MiB; home quota headroom at least 5 GiB |

The submission directory must be named `qgcomp-binary-risk-ratio-four-level-known-scores-v1`. It contains `source.bundle`, `CODE_BUNDLE_SHA256.txt`, `SOURCE_REVISION.txt`, a clean `code` checkout at that revision, an isolated `python` environment with NumPy and SciPy, and `logs/`. Both scripts verify the bundle digest, exact revision and clean checkout before fitting. Python 3.11.5, NumPy 2.0.0 and SciPy 1.14.0 are the existing server profile; record the actual versions at runtime. Each job writes timestamps, node, loaded modules, source identity, status, a retained case journal, completion receipt, checker, independent aggregation and checksums. A failed or interrupted output is retained and never resumed under the same run identity. Do not replace it silently.

No raw data transfer is needed: case inputs are generated by the committed runner. Keep full server outputs in private project validation storage. On return, verify `output-sha256.txt`, the receipt, the all-case checker and independent aggregation. Summarize successes, failures and uncertainty without treating this narrow study as broad R-package or paper validation. No R installation is needed for these jobs.
