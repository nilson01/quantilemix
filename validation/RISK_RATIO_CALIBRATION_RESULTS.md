# Marginal binary risk-ratio bootstrap: known-score study

The [reviewed protocol](RISK_RATIO_CALIBRATION_PROTOCOL.md) asked how often the implemented 200-resample normal interval contains the true *population-average log risk ratio* across new independent datasets. This is a statistical-performance question. The two fixed-input comparisons with installed R qgcomp 2.19.6 in [RISK_RATIO_RESULTS.md](RISK_RATIO_RESULTS.md) test software agreement on different, nonseparated datasets. Neither type of check establishes broad R-package or paper coverage.

Each of four planned conditions used 1,000 independent datasets with 500 rows. Four known binary exposure scores and one binary adjustment covariate were independent. A correctly specified logistic model generated the binary outcome. The contrast changes all four scores from zero to one and averages the predicted event probability over the adjustment-covariate distribution. In the table, `r0` is the all-zero intervention risk and `b` is the joint *conditional log odds* contrast. The true marginal log risk ratio is not generally `b`. The four true log ratios are 0, 0.679602, 0 and 0.396145 in table order. The scores were already assigned; this study did not estimate quantile cutpoints or make a causal claim.

All **4,000 planned datasets** were generated and recorded. The package completed 3,999 fits. In the sparse null condition, one dataset failed because bootstrap draw 83 of 200 had separated data: among its 255 rows with adjustment value zero, none had an event. The package rejected that draw; no dataset or draw was replaced. The independent checker confirmed failure at the same draw. There were no missing cases or captured package warnings. Therefore the table keeps the failure beside successful-fit coverage. The all-planned bounds show the possible fraction among all 1,000 datasets if the one unavailable interval is counted as uncovered or covered.

Bias is the mean estimate minus the known log ratio. Its parentheses give the Monte Carlo standard error (MCSE), which measures variation of the mean across independent datasets. Coverage is the fraction of successful intervals containing the truth. Square brackets give a **cellwise** 95% Wilson interval for that fraction or the rejection fraction; they do not jointly cover all four conditions. Rejection uses the same two-sided normal test as the interval. In null cells it is the false-positive rate; in nonzero cells it is descriptive power.

In the sparse null cell, the pointwise Wilson interval for successful-fit coverage lies above 0.95. The corresponding rejection interval lies below 0.05; this is the *same* interval/test behavior, not a second independent finding. The 33 observed rejections give an all-planned false-positive bound of 33–34/1,000 (0.033–0.034), depending on the failed case. One failed dataset changes the all-planned coverage by at most 0.001 and does not remove the signal. This prespecified flag warrants further study of sparse-event behavior. It is not proof that the method is systematically conservative. The other three coverage Wilson intervals include 0.95. No bias exceeds three MCSEs, and no Wilson coverage interval lies wholly outside the protocol's descriptive 0.93–0.97 investigation band. That band is not an equivalence margin. These results do not justify a general “95% calibrated” claim.

The empirical standard deviations of successful estimates were 0.5375, 0.4445, 0.2177 and 0.1910 in table order. The square roots of mean reported bootstrap variance were 0.5762, 0.4628, 0.2243 and 0.1864. These values describe the four conditions; they do not compare this interval with another method in a controlled design.

## Limits

This study covers independent rows, four already scored binary exposures, one binary adjustment covariate, one correctly specified logistic data model, two intervention levels and the implemented 200-resample normal interval. It does not test raw-exposure cutpoints, ties, other covariate distributions, rarer or more imbalanced outcomes, case weights, missing data, clusters, other bootstrap intervals, nonlinear effects, interactions, offset/count models, survival or multicategory outcomes. The one separated draw shows an operational failure mode in sparse data: the public fitting call raises an error and returns no interval for that dataset, even though the original dataset contained events. The result does not establish causal effects, wider R qgcomp behavior, or paper reproduction. It adds a narrow repeated-data check to the public-interface coverage map.
