# Conditional Cox cluster-robust uncertainty

`fit_cox(..., cluster_ids=ids)` accepts one finite, exact integer cluster ID per complete row and requires at least two clusters. The Cox coefficients still use the ordinary case-weighted partial likelihood. For uncertainty, score contributions from rows with the same ID are summed before forming the sandwich covariance. A cluster ID does not change exposure cuts, risk sets, fitted coefficients or the baseline hazard. This is a conditional joint log hazard ratio, not a population-average survival effect.

Three fixed 128-row cases were exported from **installed R qgcomp 2.19.6** in an isolated R 4.5.1 library with survival 3.8.3: distinct event times, tied times, and tied times with fractional case weights and known log-hazard offsets. Each has 16 clusters. Python and installed R agree on coefficients, covariance, joint effect, confidence limits, p-value, event count, model-based information inverse and score residuals. The largest absolute numerical gap is **8.89 × 10⁻¹⁵**. The [saved comparison](cox-cluster-reference-results.json), [optional installed-R checker](check_cox_cluster_r.py), [exporter](export_cox_cluster_r.R) and [fixed fixture](../tests/fixtures/r_cox_cluster_2_19_6.json) preserve the evidence. Python fitting has no R runtime dependency.

An independent three-person risk-set calculation checks row and cluster scores. The checker also reconstructs R's cluster sandwich from its saved model-based covariance and score residuals. `survival::residuals(type="score")` omits the case-weight multiplier in its displayed rows; the fitted robust covariance uses weighted rows. The checker applies that multiplier explicitly. Invalid IDs fail, and relabeling IDs without changing their groups preserves the fit. The current interface accepts numeric exact integer IDs only; R also accepts other cluster types. These fixed checks do not establish confidence-interval coverage across repeated clustered datasets, proportional hazards, independent censoring or causal identification.
