# Method coverage and reference checks

This map lists supported methods, open features and their checks. Fixed-input
agreement with R qgcomp does not establish interval coverage.

## Current scope and priorities

The common additive Gaussian, binary and Poisson formula routes support
categorical adjustment, positive weights and missing-row removal. `plot_weights` and `plot_response` show selected saved results without
uncertainty bands. The package follows the methods emphasized in the R
[basic](https://cran.r-project.org/web/packages/qgcomp/vignettes/qgcomp-basic-vignette.html)
and [advanced](https://cran.r-project.org/web/packages/qgcomp/vignettes/qgcomp-advanced-vignette.html)
vignettes. The tables list each method and its limits.
